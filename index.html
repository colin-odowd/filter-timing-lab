Each wake-up is delayed by 0–this many milliseconds, using repeatable random jitter.

The coefficient stays fixed

α = dt / (τ + dt)
y[n] = y[n−1] + α(x[n] − y[n−1])

This is the backward-Euler one-pole form, using your programmed time constant. Both τ and dt are in seconds. The corresponding analog cutoff is fc = 1 / (2πτ); this is a close approximation to the digital cutoff when dt is small compared with τ. Here, n counts filter updates; the graph places each result at the actual task execution time.

Digital implementation

The output holds its last value between executions. Task execution and queue processing are assumed instantaneous.


Scheduling model: the external source samples every fixed dt. Task releases follow the same absolute schedule. The selected pattern delays each execution by either a repeatable random amount from 0 to X, or exactly X milliseconds after its scheduled release. Releases passed while waiting are coalesced, and scheduling resumes at the next strictly future release. This models a latest-value mailbox or a lossless queue, not a delay in the external source itself.
